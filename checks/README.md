# checks/ — результаты проверок

- `runs/<время>-<инструмент>-<файл>/` — каждый запуск любого `tools/*.py`. Эта папка не коммитится (см. `.gitignore`).
- `latest/` — копия последнего запуска. В git попадают только `summary.md`, `log.txt`, `result.json` и контакт-листы `contact*.png`.

Состав папки запуска:

| Файл | Что внутри |
|---|---|
| `summary.md` | отчёт: время шагов, найденные проблемы, ссылки на картинки |
| `log.txt` | лог с метками времени в мс |
| `result.json` | все данные в машинном виде |
| `<файл>/slides/slide-NN.png` | рендеры слайдов PPTX |
| `<файл>/contact_sheet.png` | все слайды на одной картинке |
| `<файл>_html/desktop`, `phone` | скриншоты HTML-версии на компьютере и телефоне |
| `compare-NN.png` | после `edit.py`: «до / после / разница» |
